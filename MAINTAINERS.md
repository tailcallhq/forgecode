# Maintainers

This document lists the current maintainers of helioslite (formerly `tailcallhq/forgecode`).

## Current maintainers

- **Koosha Pari (@KooshaPari)** — Owner. Contact via GitHub @KooshaPari or through the project's GitHub Issues.

## Becoming a maintainer

The project welcomes new maintainers. To become a maintainer:

1. Have a track record of substantial, accepted contributions (PRs reviewed and merged).
2. Be nominated by an existing maintainer.
3. Be approved by unanimous consent of the existing maintainers.
4. Be added to `.github/CODEOWNERS` and this file in a single PR.

Maintainers must enable 2FA on their GitHub account (preferably hardware key or TOTP, not SMS).
